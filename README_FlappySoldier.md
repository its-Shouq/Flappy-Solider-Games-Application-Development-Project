# Flappy Soldier

Flappy Soldier is a 2D arcade game inspired by Flappy Bird. Players control an anime-style soldier flying through the sky, avoiding pipes, collecting coins, and unlocking rewards along the way.

## 🎮 Game Overview

| | |
|---|---|
| **Genre** | Action / Arcade |
| **Platform** | Mobile / PC |
| **Engine** | Unity |
| **Target Audience** | Ages 12–20, casual/arcade gamers |

The game focuses on fast, reactive gameplay — timing and coordination over storytelling — delivering the same quick-excitement loop that made tap-to-play games like *Flappy Bird* and *Subway Surfers* popular with this age group.

## ✨ Features

- **Simple, addictive controls** — tap/click to fly upward and navigate through narrow gaps between pipes
- **Coin collection system** tied to in-game rewards
- **Shield power-up** — collecting a set number of coins (e.g., 3) grants temporary collision protection
- **Cup reward system** — earn a **Silver Cup** for passing 10 pipes, and a **Gold Cup** for passing 20 pipes
- **Chibi/anime-style character design**, chosen to appeal to the target audience and support future shop-based customization

## 🕹️ Gameplay

**Controls:** Tap / Click (Space) to move the character upward

**Challenge type:** Physical coordination — timing taps correctly to stay centered in gaps while deciding when to risk collecting coins

**Win condition:** Survive for a set duration (e.g., 40 seconds)

**Game over condition:** Character collides with a pipe

## 🛠️ Built With

- **Unity** — game engine
- **C#** — gameplay scripting
